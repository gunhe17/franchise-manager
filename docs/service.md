# Service

## 1. 운영 주체와 대상

- **운영 주체**: Two Star Global (유통업체)
- **대상**: Two Star Global이 납품하는 프랜차이즈 영업점의 **프랜차이즈 대표 및 계약자**

## 2. 서비스 목적

프랜차이즈 각 가맹점의 추가적인 유입 효율을 높이기 위해, 프랜차이즈 대표들을 대상으로 운영한다.

## 3. 핵심 기능

각 가맹점의 주문 중 일부 비율 만큼의 금액을 프랜차이즈 대표 및 계약자에게 제공한다.

- 보상 형식: **상품권** (추후 변동 가능성 존재)
- 구현 방식: **내부 포인트로 적립**하고, 사용자가 **금액 + 지급 방식(상품권 등)** 을 선택해 신청, 운영자 승인을 거쳐 지급
- 적립 시점: **실시간 / 주문 건별 적립**

> 도메인 모델, 리워드 계산 정책, 포인트 원장, 주문 인입, 상품 교환 워크플로 등 도메인 특화 정보는 [datamodel.md](datamodel.md) 참조.

## 4. 서버 구성

| 서버 | 대상 | 기술 스택 |
| --- | --- | --- |
| `client` | 프랜차이즈 대표 · 계약자 | Svelte |
| `admin` | Two Star (운영자) | Svelte |
| `api` | (공용) | FastAPI + PostgreSQL |

## 5. 인증 / 권한

### 5.1 User (프랜차이즈 대표 · 계약자)

- **휴대폰 번호 + 비밀번호** 로그인
- **카카오톡 소셜 로그인** 지원 (휴대폰 번호 없이도 가입 가능 — [datamodel.md §3.3](datamodel.md) 참조)

### 5.2 Admin (Two Star 운영자)

- **이메일 + 비밀번호** 로그인 (비밀번호 해시는 argon2id 권장)

### 5.3 Admin 역할

- **`super_admin`**: 모든 관리 기능 (CRUD, 승인, 포인트 보정, 카탈로그 관리 등)
- **`viewer`**: 조회 전용
